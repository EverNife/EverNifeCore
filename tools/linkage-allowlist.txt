# References this project knowingly compiles against a shape or a member some supported server
# does not have. Every line names the guard that keeps the reference from being reached there.
#
#   <runtime> <kind> <reference> <site>   # <how it is guarded>
#
# <runtime> is a target id from checkLinkage's own listing, or '*' for "wherever it is absent".
# <kind> is class | field | method | shape.
# <site> is the compiled class the reference lives in, as the class file names it (nested classes
# carry their '$'). An exception covers that class and no other: the same reference compiled into a
# second class is a second decision, and it has to be made rather than inherited.
#
# A reference with no guard does not belong here. It is a defect, and the way out is the ladder
# checkLinkage prints when it fails - not a line in this file. An entry nothing needs any more
# fails the build too: a leftover exception authorizes whatever walks in next.
