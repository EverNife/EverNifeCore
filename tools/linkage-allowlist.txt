# References this project knowingly compiles against a shape or a member some supported server
# does not have. Every line names the guard that keeps the reference from being reached there.
#
#   <runtime> <kind> <reference>   # <the site that guards it, and how>
#
# <runtime> is a target id from checkLinkage's own listing, or '*' for "wherever it is absent".
# <kind> is class | field | method | shape.
#
# A reference with no guard does not belong here. It is a defect, and the way out is the ladder
# checkLinkage prints when it fails - not a line in this file.
